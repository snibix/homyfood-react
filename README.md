# Homyfood

HomyFood est un projet initialement réalisé sans React, puis refait avec React pour la pratique et l'apprentissage de cette bibliothèque. Cette application présente une liste de restaurants avec des détails dynamiques et une navigation fluide grâce à React Router. Déployée sur GitHub Pages, elle est compatible avec les routes dynamiques en utilisant HashRouter.

## Fonctionnalités

- Page d'accueil : Affiche une liste de restaurants sous forme de cartes
- Détails des restaurants : Chaque restaurant a une page dédiée accessible en cliquant sur une carte.
- Navigation fluide : Retour vers l'accueil depuis la page des détails.
- Gestion des erreurs : Une page "404 Not Found" est affichée pour les routes inexistantes.
- Déploiement sur GitHub Pages : Utilisation de HashRouter pour gérer les routes dynamiques.

## Technologies utilisées

- React : Pour la création de l'interface utilisateur.
- ** React Router** : Pour la gestion de la navigation.
- FontAwesome : Pour les icônes.
- SCSS : Pour la gestion des styles.

## Installation

1. Clonez ce dépôt sur votre machine locale :

```bash
git clone https://github.com/votre-repo.git`
```

2. Installez les dépendances :

```bash
npm install
```

3. Lancez l'application en mode développement :

```bash
npm start
```
